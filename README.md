# Level 0 English Lessons

Interactive lesson pages for adult beginners (Pre-A1). Teachers open a lesson in the browser and teach from a projector: 7 steps, 70 minutes, with audio, a timer and teacher notes.

Open `index.html` to see all weeks and lessons.

## Folder layout

```
index.html            course home: all 8 weeks
week-1/lesson-1.html
week-1/lesson-2.html
week-1/lesson-3.html
```

Each lesson page is a single self-contained file. Fonts load from Google Fonts; everything else is inside the file.

## Put it online with GitHub Pages

1. Push these files to the repository.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Notes

- Audio uses the browser's built-in English voices. Chrome and Edge usually have the best ones. Teachers can change the voice and turn on a slow voice in the top bar.
- Letter-sound audio plays the example word (sun, apple, tiger). The teacher models the single sound.
